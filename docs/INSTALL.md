# Installation Guide

## Requirements

- Windows 10 (1903+) or Windows 11 (21H2+)
- 4 GB RAM minimum
- Administrator permissions

## Steps

1. Download `RocoAutoCapture.zip` from [Releases](https://github.com/CentaurQuailAtrium/roco-kingdom-world-auto-capture/releases/latest)
2. Extract with WinRAR or 7-Zip
3. Enter password: `6427910552`
4. Install Interception driver (included in archive)
5. Right-click `RocoAutoCapture.exe` → **Run as Administrator**
6. Launch Roco Kingdom: World and enable modules

## Portable mode

No installation required. The tool is a single native executable.

## Uninstall

Delete the folder. Uninstall Interception driver if no longer needed.
