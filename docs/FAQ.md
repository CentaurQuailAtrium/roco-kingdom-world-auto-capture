# Frequently Asked Questions

## Is it safe?

The tool uses Interception driver instead of memory modification, which is harder to detect. However, no automation tool is 100% safe. Use at your own risk.

## Why is the archive so small?

Native C++ build. No Electron, no .NET runtime, no bundled installers.

## Why does my antivirus flag it?

Automation tools that install drivers always trigger heuristic detection. Add the folder to exclusions.

## Does it work on Windows 11 24H2?

Yes. Full support for Windows 10 and 11.

## Does it work with the PC client?

Yes. Designed for the PC client.
