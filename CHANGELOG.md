# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] — October 2026

### Added
- Auto capture (creature detection, ball throw, shiny detection)
- Battle automation (skill release, custom sequences)
- Route replay (recording, replay, teleport anchors)
- Interception driver support
- Native C++ build, 1.8 MB, no runtime dependencies
