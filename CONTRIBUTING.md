# Contributing

Thanks for your interest in improving Roco Kingdom World Auto Capture!

## How to contribute

1. Fork the repository
2. Create a feature branch (`git checkout -b feature/my-feature`)
3. Commit your changes
4. Push to the branch
5. Open a Pull Request

## Guidelines

- Keep the tool local-only (no cloud sync)
- No external dependencies
- Test on Windows 10 and Windows 11
- Update CHANGELOG.md

## Reporting bugs

Open an issue with:
- Windows version
- Roco Kingdom version
- Steps to reproduce
- Expected vs actual behavior
